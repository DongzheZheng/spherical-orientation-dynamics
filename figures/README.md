# Figure guide

`reference/` contains twelve English PDFs. `source/` contains ten editable standalone TeX sources. The two 3D figures are generated by Python. TeX plots read the CSVs through `../numerics/data/`; the reproduction runner stages them in the regenerated output tree with that relative layout.

| Figure | Physical question |
| --- | --- |
| `spectrum.pdf` | How do the transverse and radial angular rates separate as alignment strengthens? |
| `fold.pdf` | Where does the ordered equilibrium branch turn, and how does pressure behave near the fold? |
| `slow_rate.pdf` | How does the guaranteed self-consistent relaxation threshold change along a branch? |
| `phase_landscape.pdf` | Which uniform and ordered equilibria are minima or barriers at fixed density? |
| `quench_dynamics.pdf` | Can two initial states at the same density relax to different equilibria? |
| `gci_symbol.pdf` | How does the GCI coefficient enter pressure and the propagation discriminant? |
| `transport_atlas.pdf` | How do angle and feedback law change real and imaginary SOH characteristic speeds? |
| `fold_angle_wedge.pdf` | What angular wedge and speed scaling emerge near the ordered fold? |
| `noise_phase_map.pdf` | How does saturated feedback change the zero-pressure boundary? |
| `orientation_sphere.pdf` | What is an orientation density on a unit sphere, and what does an infinitesimal turning response look like? |
| `energy_landscape_3d.pdf` | How do a uniform minimum, barrier ring and ordered ring appear in polarization-vector space? |
| `physical_mechanism.pdf` | How are angular relaxation, self-consistent basins and spatial SOH coupling related? |

The final figure is qualitative: its three panels describe linked mechanisms, not consecutive frames of a trajectory. The energy surface is a cross-section of the fixed-polarization free-energy envelope. The unit sphere's radius is geometry, not probability. Consult `numerics/README.md` for the measure convention and the exact meaning of these visualizations.
